定义1.2.4 (数列极限的“ε-N语言”) 设有数列{x_n}, 若存在 A ∈ R, 对于任意的 ε > 0, 存在 N ∈ N, 使得当 n > N 时, 恒有 |x_n - A| < ε,
则称数列{x_n}以A为极限, 也称{x_n}收敛于A, 记为 lim x_n = A, 或 x_n -> A (n -> ∞).
n->∞
并称数列{x_n}为收敛数列, 反之称{x_n}为发散数列。

定理1.2.1 (唯一性) 收敛数列的极限是唯一的。
证明 用反证法。假设数列{x_n}的极限不唯一, 不妨设其极限分别为 A, B, 且 A ≠ B,
即此时我们有 lim x_n = A 以及 lim x_n = B. 我们取 ε = |A - B| / 2 > 0, 则 ∃ N ∈ N, 当 n > N 时, 我们有 |x_n - A| < ε, |x_n - B| < ε, 注意到 2ε = |A - B| = |A - x_n + x_n - B| <= |A - x_n| + |x_n - B| < 2ε.

定义1.2.7 (数列极限的“G-N语言”) 设有数列{x_n}, 若对于任意的 G > 0, 存在 N ∈ N, 当 n > N 时有 x_n > G (或 x_n < -G, |x_n| > G) 成立, 则称 n -> ∞ 时 {x_n} 是一个正无穷大量 (或负无穷大量, 无穷大量), 习惯上也说, {x_n} 以 +∞ (或 -∞, ∞) 为极限, 记为 lim x_n = +∞, (或 lim x_n = -∞, lim |x_n| = ∞).

定义1.2.8 (“ε-δ语言”) 设函数 f(x) 在 x_0 的某个去心邻域 N(x_0) 内有定义, A 为一给定的常数, 若对于任意的 ε > 0, 存在 δ > 0, 使得当 0 < |x - x_0| < δ 时, 都有 |f(x) - A| < ε,
则称 f(x) 当 x 趋于 x_0 时的极限为 A, 记作 lim f(x) = A, 或 f(x) -> A (x -> x_0).
x->x_0

·核心:在一个区间上 f⁽ⁿ⁺¹⁾(x) 存在。
·蕴含:此条件蕴含(3)和(2)。
·应用:拉格朗日(Lagrange)型泰勒公式(展开到 n 阶)的必要条件。因为其余项显式包含 f⁽ⁿ⁺¹⁾(ξ)。

逻辑关系与泰勒公式适用性
逻辑关系:(4) ⇒ (3) ⇒ (2) ⇒ (1)
(反向推导均不成立)

泰勒公式要求:
·皮亚诺余项:仅需条件(1)。
·拉格朗日余项:需要条件(4)。

1. 在 x=0 处 3 阶可导,但不满足 2, 3, 4
函数:
f(x) = {x³sin(1/x) x≠0
        {0 x=0
