4.  5.  证明：① A 有限
lim (n->∞) Xn = A <=> ∀ε>0, ∃N, ∀n>N, |Xn - A| < ε

先固定下 ε, 根据 ε 再固定一个 N1, 使 n > N1 时，恒有 (Xn - A) < ε
则 lim (n->∞) 1/n (X1 + X2 + ... + Xn) = lim (n->∞) 1/n (X1 + ... + XN1) + lim (n->∞) 1/n (XN1+1 + ... + Xn)
n -> ∞ 时，1/n (X1 + ... + Xn) -> 0, 故 (*) = lim (n->∞) 1/n (XN1+1 + ... + Xn) (**)
∴ n > N1 时，|Xn - A| < ε
∴ |(**) - A| <= 1/n (|XN1+1 - A| + ... + |Xn - A|) <= (n - N1)/n * ε <= ε
∴ 即 lim (n->∞) 1/n (X1 + ... + Xn) = A

② A = ±∞, 不妨只考虑正 ∞ 时 (负 ∞ 时方法，同理)
对 ∀G, ∃N2, n > N2, Xn > G
仍拆成两部分：lim (n->∞) 1/n (X1 + ... + Xn) = lim (n->∞) 1/n (X1 + ... + XN2) + lim (n->∞) 1/n (XN2+1 + ... + Xn)
lim (n->∞) 1/n (X1 + ... + XN2) = 0, lim (n->∞) 1/n (XN2+1 + ... + Xn) > (n - N2)/n * G
∴ lim (n->∞) N2/n = 0, ∴ lim (n->∞) 1/n (XN2+1 + ... + Xn) > G
即 ∀G, ∃N, n > N 时，1/n (X1 + ... + Xn) > G
即 lim (n->∞) 1/n (X1 + X2 + ... + Xn) = ∞ (-∞ 情况同理)
