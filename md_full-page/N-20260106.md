## 第 4 页

结论1: 积分区间 [-π/2, π/2]

∫(-π/2)^(π/2) 1/(a + b cos x) dx = 2/√(a² - b²) arccos(b/a),

其中 a > 0, |b| < a。

这个结果也可以写成半角形式: 令 θ = arccos(b/a), 则

arccos(b/a) = 2 arctan √(a-b)/(a+b)

所以等价于

4/√(a² - b²) arctan √(a-b)/(a+b)

结论2: 积分区间 [0, π]

∫0^π 1/(a + b cos x) dx = π/√(a² - b²),

其中 a > 0, |b| < a。

这是更常见的一个标准结果,用万能代换直接得到,上下限对称到整个半周期,积分更简单。

Wallis 公式通常从 Wallis 积分推导:

I_n = ∫0^(π/2) sin^n x dx

得到递推关系:

I_n = (n-1)/n I_(n-2)

并比较偶次项 I_(2n) 与奇次项 I_(2n-1) 的比值, 令 n → ∞ 可得 Wallis 乘积公式。
